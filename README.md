# کافه باتری — ریدیزاین لندینگ فروشگاه

ریدیزاین کامل لندینگ فروشگاه تخصصی باتری [کافه باتری](https://cafebattery.com/) — تک‌فایل `index.html` (راست‌چین، فارسی، تم روشن).

## ساختار صفحه

هدر فروشگاهی (نوار کاربردی + لوگو + ناوبری + سرچ + حساب/علاقه‌مندی/سبد، چسبان) ← هیرو ← نوار اعتماد ← ۱۲ دسته‌بندی ← خرید بر اساس کاربرد (۴ کارت) ← پرفروش‌ها (۵ کارت) ← یابنده باتری ۳ مرحله‌ای (تعاملی) ← اسپات‌لایت Maxcell ← جدیدترین‌ها ← دانشنامه + اخبار ← مشاوره ← فوتر

## فایل‌ها

- `index.html` — لندینگ کامل
- `img/` — عکس‌های لوکال (آفلاین‌محور)
- `parts/` — تکه‌های سورس (p1 تا p8؛ اسمبل با `cat parts/p*.html > index.html`)

## سیستم دیزاین

- پالت: سرمه‌ای `#14213D`، فیروزه‌ای `#16C1D4`، زرد باتری `#F4C542` (اکسنت)، پس‌زمینه `#F6F8FA`، بردر `#E2E8F0`
- فونت وزیرمتن، اعداد فارسی
- سئو: تایتل/دسکریپشن فارسی، canonical، Open Graph، اسکیمای ElectronicsStore و FAQPage، alt فارسی
- تعامل‌ها: سبد/علاقه‌مندی با شمارنده و تستی، یابنده باتری ۳ مرحله‌ای، آکاردئون سوالات

## پیش‌نمایش لوکال

کافیست `index.html` را در مرورگر باز کنید.
