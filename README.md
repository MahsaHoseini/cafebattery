# کافه باتری — ریدیزاین لندینگ

ریدیزاین مدرن لندینگ فروشگاه تخصصی باتری [کافه باتری](https://cafebattery.com/) — تک‌فایل `index.html` (راست‌چین، فارسی).

## ساختار

- `index.html` — لندینگ کامل (هیرو، دسته‌بندی‌ها، پرفروش‌ها، ساخت سفارشی پک، باشگاه همکاران، نظرات، سوالات پرتکرار، تماس، فوتر)
- `img/` — عکس‌های لوکال (آفلاین‌محور، بدون وابستگی به CDN)
- `parts/` — تکه‌های سورس صفحه (p1 تا p6؛ اسمبل با `cat parts/p*.html > index.html`)

## ویژگی‌ها

- فونت وزیرمتن + مرکزیتکست، اعداد فارسی، پالت ذغالی + کهربایی انرژی
- سئوی اولیه: تایتل/دسکریپشن فارسی، canonical، Open Graph، اسکیمای ElectronicsStore و FAQPage، alt فارسی
- ریسپانسیو (دسکتاپ + موبایل با نوار تماس چسبان)

## پیش‌نمایش لوکال

کافیست `index.html` را در مرورگر باز کنید.
